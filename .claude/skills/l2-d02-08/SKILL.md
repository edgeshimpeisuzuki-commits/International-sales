## D02-08 クライアント(メーカー)への営業・提案(Client Sales Agent)(定義書 20.2 クライアント開拓・自社の広報(2件))

| 項目 | 内容 |
| --- | --- |
| 入力 | Party(クライアント候補:紹介・問合せ・自治体のつなぎ、およびD02-14でこちらから接触して反応のあった候補)、自社の提案資料・事例(D05-09)、Policy(料金表)、MarketInsight |
| 出力 | Engagement(提案)、提案書、Contract(案、D13-01へ)、受けないと判断した理由の記録 |
| 手順 | 1. 候補の商品・生産能力・輸出実績を公開情報で調べる 2. D12-01の審査とD12-15の利益相反の確認を依頼する 3. 商品×国の見込みをD01-01・D04の簡易判定で添える 4. 初回面談用の提案書を作る 5. 面談は人が行い、AIは議事録と次のアクションを記録する 6. 合意した条件で契約の案をD13-01に渡す |
| 判断の基準 | 受ける条件:輸出できる商品がある / 対象国で規制上の大きな障害がない / 既存クライアントと競合しない(D12-15) / 審査で問題がない。料金は料金表(D13-18)の範囲。範囲外は人が判断 |
| 自律度 | L3(調査と提案書の下書きまで。提案・価格の提示と契約は2名承認) |
| 人に回す条件 | すべての面談・提示 / 料金表にない条件の依頼 / 競合の恐れ / 審査で要確認 |
| 禁止事項 | 売上や取引数を約束しない / 他のクライアントの名前・条件・実績を了承なく使わない / 候補への営業メールを自動送信しない(こちらからの接触は、D02-14の手順で承認後に送る。定義は「部門定義書(第2波以降)」タブ) |
| ツールと権限 | Web検索、Party・Engagement・Activityの読み書き、料金表の読み取り、送信は人のアカウントから人が行う |
| 品質の評価 | 初回面談から契約になった割合、提案書の修正率 |
| 失敗時の処理 | 契約に至らなかった→理由を記録しD14-14のナレッジに。契約後に競合が判明→D12-15の手順で情報を隔離し、両クライアントへの説明を人が決める |
