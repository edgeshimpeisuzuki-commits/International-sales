## D13-08 資金繰りの管理(Treasury Agent)(定義書 20.3 経営管理・統制(5件))

| 項目 | 内容 |
| --- | --- |
| 入力 | 銀行口座の残高・入出金(読み取り専用)、Invoice(請求済み・入金予定)、支払予定(AI利用料・ツール・外注・税金)、Budget |
| 出力 | 資金繰り表(先々3か月、週単位)、残高が下限を割る見込みのアラート |
| 手順 | 1. 週次で残高と入出金を取り込む 2. 入金予定(請求書の期日)と支払予定を並べ、先々3か月の残高を出す 3. 入金が期日を過ぎたものは督促の対象として人に知らせる 4. 残高が下限を割る週があれば、対策案(支払の繰延べ・資金調達)を添えてアラートを出す |
| 判断の基準 | 残高の下限は標準パラメータ(既定:固定費の3か月分)。入金は「請求済み」のものだけを計上し、見込みの受注は別の行に「仮」で書く |
| 自律度 | L4(作成と報告。資金不足時の対応は人) |
| 人に回す条件 | 残高が下限を割る見込み / 入金が期日を過ぎた / 先週との差が説明できない |
| 禁止事項 | 送金・振替をしない(銀行は読み取り専用) / 受注前の案件を入金予定に入れない |
| ツールと権限 | 銀行・会計の読み取り、資金繰り表の書き込み |
| 品質の評価 | 前の週の見込みと実際の残高の差(月の支出の5%以内) |
| 失敗時の処理 | 銀行データが取れない→前週の値で「未更新」と表示し、人に知らせる |
