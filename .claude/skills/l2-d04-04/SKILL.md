## D04-04 現地ラベルの作成(Compliance Agent)(定義書 22.11 P2の定義 第2弾:初回の取引と月次の締め(10件、11/14))

| 項目 | 内容 |
| --- | --- |
| 入力 | 商品マスタ(原材料・内容量・賞味期限)、国のマスタの表示ルール、買い手の要望(小売用か業務用か) |
| 出力 | ラベルの文案(現地語・英語)、表示項目のチェック表、確認が必要な点 |
| 手順 | 1. 小売用か業務用かを確かめる(業務用の大袋だけなら不要な場合がある) 2. 表示ルールに沿って文案を作る 3. チェック表とともにクライアントに送る(承認後) |
| 判断の基準 | 効能の表示はD04-07の基準で確かめる。最終の確認はクライアント(または現地の輸入者・専門家)が行う |
| 自律度 | L2 |
| 人に回す条件 | すべての送付 / アレルゲン・効能に関わる表示 |
| 禁止事項 | 共通の禁止事項。商品マスタにない情報を書かない |
| ツールと権限 | 商品・国のマスタの読み取り、文案の作成 |
| 品質の評価 | クライアント・輸入者の修正の件数 |
| 失敗時の処理 | 誤りが出荷後に判明→D12-10(重大度 高)へ |
