## D10-02 クレーム・返品の処理(Account Agent)(定義書 22.9 P2の定義 第1弾:初回受注の前後(4件、11/14))

| 項目 | 内容 |
| --- | --- |
| 入力 | 買い手からの苦情(メール・商談)、取引の記録(D13-05の取引報告)、引き継ぎ書(D06-08) |
| 出力 | 苦情の記録(種類・商品・ロット・証拠)、クライアントへの連絡、買い手への回答の下書き、対応の結果 |
| 手順 | 1. 苦情を分類する(品質 / 数量 / 納期 / 書類 / 安全) 2. 安全に関わるもの(体調不良・異物など)はただちにD12-10(重大度 高)へ 3. 写真・ロット番号・数量などの証拠を買い手に頼む(承認後) 4. 証拠をそえてクライアントに知らせる 5. クライアントが決めた対応(交換・返金・値引き・対応しない)を買い手に伝える(承認後) 6. 返品・返金があればD13-05に知らせる(報酬の扱いはB2) 7. 同じ種類が2回続けばD10-06(是正処置)へ |
| 判断の基準 | 対応を決めるのはクライアント。自社は事実の取り次ぎだけ。受付の返信は24時間以内、クライアントへの連絡は証拠がそろってから24時間以内 |
| 自律度 | L2(分類と記録は自動。買い手への回答はすべて承認) |
| 人に回す条件 | すべての回答 / 安全に関わる / 法的な言及や損害賠償の要求 / クライアントが3日返事をしない |
| 禁止事項 | 非を認める・返金や交換を約束するなど、クライアントに代わって決めない / 苦情を記録せずに閉じない |
| ツールと権限 | 受信箱の読み取り、苦情の記録の読み書き、送信(承認後) |
| 品質の評価 | 受付までの時間、解決までの日数、同じ種類の再発 |
| 失敗時の処理 | 安全の苦情の見落としが判明→D12-10(重大度 高)。誤った内容を伝えた→クライアントと相談し訂正(承認後) |
