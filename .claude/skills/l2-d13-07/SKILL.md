## D13-07 クライアント(メーカー)向けレポート(Reporting Agent)(定義書 15.2 D13 コーポレート(4件))

| 項目 | 内容 |
| --- | --- |
| 入力 | Program、Activity、Deal(失注理由を含む)、SalesOrder、紹介登録の台帳、Commission、月次の振り返りメモ |
| 出力 | 月次レポート(クライアントに見せる外部ビュー) |
| 手順 | 1. 月初に前月の数字を集計する 2. 下の構成で下書きを作る 3. 承認後に送る |
| 判断の基準 | 構成はクライアント設定の報告項目に従う。標準の項目は:顧客候補数、反応(返信・商談)、ニーズ、発注に至らない原因、有効だった営業手法。加えて、紹介登録の一覧、見積・受注、クライアントにお願いしたいこと、来月の計画 |
| 自律度 | 集計と下書き:L4。送付:L3(P1では毎回承認) |
| 人に回す条件 | 全件(送付前の確認) |
| 禁止事項 | 成果を盛らない(商談数・受注数など数えられるもので書く) / 別のクライアントの情報を混ぜない / 買い手の担当者の個人情報は必要な範囲だけにする |
| ツールと権限 | 各データの読み取り、レポートの作成、承認後の送付 |
| 品質の評価 | クライアントからの質問・訂正の数、送付の遅れ0回(毎月5日まで) |
| 失敗時の処理 | 集計に必要なデータが欠けている→「未集計」と明記して送り、推計で埋めない |
