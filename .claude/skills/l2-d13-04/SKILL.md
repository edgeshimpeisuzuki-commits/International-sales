## D13-04 税務申告の準備(Accounting Agent)― P1は税理士に渡す資料づくりまで(定義書 22.8 前倒しした2件の定義(11/14))

| 項目 | 内容 |
| --- | --- |
| 入力 | LedgerEntry・証憑の保存記録・源泉徴収の記録(D13-25)、報酬の請求と入金(D13-05)、Contract(個人への外注先)、税理士からの必要資料の一覧、税の期限の一覧(D12-11) |
| 出力 | 申告ごとの資料一式(残高試算表、売上・経費の明細、個人への支払いと源泉徴収の一覧、消費税の集計)、不足資料の一覧、税理士への送付の記録 |
| 手順 | 1. 税の期限をD12-11に登録し、期限の30日前に準備を始める 2. 対象期間の帳簿を締め、証憑のない仕訳と未照合の取引を洗い出す 3. 税理士の必要資料の一覧に沿って資料を作る 4. 足りない資料を人に依頼する 5. 資料一式を承認に回し、税理士に送る 6. 税理士の質問に答える資料を作る 7. 申告・納付の完了を人が記録し、D12-11の期限を消す |
| 判断の基準 | 個人事業の主な期限:源泉所得税(納期の特例なら1/20・7/10)、支払調書などの法定調書(1/31)、所得税の確定申告(3/15)、消費税(課税事業者なら3/31。インボイス登録のB3で決まる)。法人化後は決算日から2か月が期限(D13-23で切替)。税の判断(経費になるか、課税区分など)は税理士に確認し、AIが確定しない |
| 自律度 | L2(集計と資料づくりは自動。税理士への送付は承認、申告と納付は人) |
| 人に回す条件 | 税理士への送付のすべて / 証憑のない仕訳が残る / 税の判断が必要 / 期限の7日前に資料がそろっていない |
| 禁止事項 | 申告書を提出しない・納付しない / 税の判断を確定しない / 締めた帳簿を承認なしに変えない |
| ツールと権限 | 会計ソフトと証憑の保存先の読み取り、資料の作成。税理士への送付は承認後 |
| 品質の評価 | 期限に遅れた件数(目標0)、税理士からの資料の差し戻しの件数 |
| 失敗時の処理 | 期限に間に合わない→ただちに人と税理士に知らせ、D12-10(重大度 高)へ。資料の誤りが提出後に判明→税理士に知らせ、修正申告などは人が決める |
