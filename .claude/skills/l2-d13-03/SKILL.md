## D13-03 会計記帳(月次の締め)(Accounting Agent)(定義書 22.11 P2の定義 第2弾:初回の取引と月次の締め(10件、11/14))

| 項目 | 内容 |
| --- | --- |
| 入力 | D13-25の仕訳・証憑、報酬の請求と入金(D13-05)、固定報酬の請求(D11-08)、銀行・カードの明細 |
| 出力 | 月次の試算表、売上(報酬)の計上、未照合の一覧 |
| 手順 | 1. 月末に売上(報酬)を計上する 2. 銀行・カードの明細と仕訳を照合する 3. 試算表を作り、締めの確定を承認に回す 4. 締めた月は変更できないようにする |
| 判断の基準 | 締めは翌月10日まで。勘定科目の判断が分かれるものは税理士に確認 |
| 自律度 | L3(計上・照合は自動。締めの確定は承認) |
| 人に回す条件 | 締めの確定 / 照合が合わない / 締めた月の修正 |
| 禁止事項 | 締めた月を承認なしに変えない / 銀行の認証情報を記録しない |
| ツールと権限 | 会計ソフトの読み書き(締めた月は読み取りのみ)、明細の読み取り |
| 品質の評価 | 締めの遅れ、未照合の件数 |
| 失敗時の処理 | 締め後に誤り→翌月に訂正の仕訳を入れる(承認後) |
