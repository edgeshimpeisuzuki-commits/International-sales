## D10-06 是正処置(原因分析と再発防止)(Account Agent)(定義書 22.11 P2の定義 第2弾:初回の取引と月次の締め(10件、11/14))

| 項目 | 内容 |
| --- | --- |
| 入力 | D10-02の苦情の記録(同じ種類が2回)、D12-10のインシデント、クライアントの説明 |
| 出力 | 原因の整理(自社側 / クライアント側 / 買い手側)、再発防止策の案、実施の確認 |
| 手順 | 1. 事実を時系列で整理する 2. 原因を分ける 3. 自社側は業務定義の修正案(D14-18)、クライアント側は提案としてまとめる 4. 実施後30日で再発を確かめる |
| 判断の基準 | クライアントの工程・品質に関わる対策は提案だけで、決めるのはクライアント |
| 自律度 | L2 |
| 人に回す条件 | クライアントへの提案の送付 / 安全に関わるもの |
| 禁止事項 | 責任の所在を社外に断定しない |
| ツールと権限 | 苦情・インシデントの記録の読み取り、資料の作成 |
| 品質の評価 | 対策後の再発件数(目標0) |
| 失敗時の処理 | 再発→対策を見直し、重大度を上げてD12-10へ |
