## D13-23 法人化に伴う切替え((人)+Legal Agent)(定義書 20.5 新設2件)

| 項目 | 内容 |
| --- | --- |
| 入力 | LegalEntity(個人事業→法人)、Contract(全クライアント・外注先・ツールの契約)、各種アカウント(メール・AI・銀行・データの置き場)、2名が作ったもの(ツール・指示文・定義書・見込客リスト・資料)、登録(インボイス・許認可) |
| 出力 | 切替え台帳(対象・名義の変更方法・相手への通知・期限・状態)、契約の地位の移転または再契約の案(D13-01へ)、通知文の案 |
| 手順 | 1. P1から、新しい契約・アカウント・登録ができるたびに台帳に追加する 2. 法人化が決まったら、対象ごとに「名義変更 / 地位の移転 / 再契約 / 新規登録」を決める 3. クライアントへの通知と契約の案を作る 4. 切替日を決め、前後の請求・報酬の切れ目(どちらの名義で請求するか)を決める 5. すべての状態が「完了」になるまで週次で追う |
| 判断の基準 | 契約の地位の移転に相手の同意が必要なものは、同意を取るか再契約。送信はクライアントのアドレスで行うため、法人化で変わるのは送信者の名義の表記(署名・法定表示)と契約で、クライアントの了承を得てから切り替える(11/15変更)。個人で作ったツール・指示文・定義書・見込客リストなどは、譲渡か利用の許諾かを書面で決めて法人に移す(A19と合わせて専門家に確認。11/15追加)。税務・登記は専門家の助言に従う |
| 自律度 | L2(台帳と案まで。契約・登録・通知は2名承認) |
| 人に回す条件 | すべての契約・通知・登録 / 相手が同意しない |
| 禁止事項 | 相手の同意なく法人名義で請求しない / 口座・アカウントの認証情報を台帳に書かない |
| ツールと権限 | Contract・LegalEntityの読み取り、台帳の書き込み、案の作成 |
| 品質の評価 | 切替日に未完了の項目数(目標0)、切替後に見つかった台帳外の契約(目標0) |
| 失敗時の処理 | 台帳外の契約が判明→台帳に追加し、同じ手順で切替える。個人名義の入金が続いた→税理士と処理を決める |
