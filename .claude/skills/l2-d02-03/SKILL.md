## D02-03 商品情報の取込み / D02-11 仕入価格表の取込み(Product Data Agent)(定義書 16.1 市場・商品・価格(6件))

| 項目 | 内容 |
| --- | --- |
| 入力 | クライアントの仕様書・カタログ・英語サイトの商品情報、提供価格表(価格レンジ・MOQ) |
| 出力 | Product・SKU(成分・産地・加工工程・包装・賞味期限・重量・寸法)、HSCode(案)、PriceList(仕入:数量段階別の単価、有効期間、版) |
| 手順 | 1. 資料を受け取る 2. 項目ごとに抽出し、どの資料のどこから取ったかを記録する 3. 欠けている項目の一覧と、クライアントへの質問案を作る 4. 登録し、D04(適合判定)とD03(価格)を起動する |
| 判断の基準 | 資料どうしで値が食い違う場合は、新しい日付の資料を仮に採用し、「要確認」を付ける。価格表は版と有効期間を必ず持つ |
| 自律度 | L4(登録と更新は事後報告) |
| 人に回す条件 | 価格が前の版から10%以上変わった / 資料どうしの食い違いが成分・アレルゲン・産地に関わる |
| 禁止事項 | 欠けている項目を推測で埋めない / 仕入価格を社外向けのデータ(カタログ・提案書)に入れない |
| ツールと権限 | 受け取った資料の読み取り(外部入力としてD14-08を通す)、Product・SKU・PriceList(仕入)の書込み |
| 品質の評価 | 登録後に見つかった誤りの件数、要確認の滞留日数 |
| 失敗時の処理 | 読めない資料(画像のみなど)→人に回し、登録は「下書き」のままにする |
