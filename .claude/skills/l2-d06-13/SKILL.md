## D06-13 買い手側のサプライヤー登録への対応(Deal Agent)(定義書 22.11 P2の定義 第2弾:初回の取引と月次の締め(10件、11/14))

| 項目 | 内容 |
| --- | --- |
| 入力 | 買い手の登録用紙・ポータルの項目、クライアントの会社情報・認証書(D06-12) |
| 出力 | 記入の下書き、クライアントに確認が必要な項目の一覧 |
| 手順 | 1. 項目を「手元の情報で埋まる / クライアントに聞く」に分ける 2. 下書きを作る 3. クライアントに送り、確認と提出を頼む(承認後) |
| 判断の基準 | 登録の名義はクライアント。口座・税番号などは自社で埋めずクライアントが記入する |
| 自律度 | L2 |
| 人に回す条件 | すべての送付 / 自社が契約当事者になるよう求められた |
| 禁止事項 | クライアント名義で提出しない / 口座情報を扱わない |
| ツールと権限 | 書類の読み取りと下書き、送信(承認後) |
| 品質の評価 | 登録の差し戻し件数 |
| 失敗時の処理 | 差し戻し→理由を記録し、クライアントと直す |
