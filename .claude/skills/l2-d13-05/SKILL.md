## D13-05 報酬・手数料の計算(Billing Agent)(定義書 15.2 D13 コーポレート(4件))

| 項目 | 内容 |
| --- | --- |
| 入力 | SalesOrder(受注確定)、Contract(報酬の条件)、紹介登録の台帳(D06-16) |
| 出力 | Commission(受注ごとの報酬額と根拠)、月次の報酬明細、請求書の下書き |
| 手順 | 1. 受注が確定したら、買い手が紹介顧客として登録確定済みか確かめる 2. その買い手の初回受注日からの経過で率を決める(率はクライアント設定の報酬条件に従う) 3. 報酬額を計算し根拠と一緒に記録する 4. 月末に明細をまとめ、クライアントへの確認と請求を承認に回す 5. 月末から7日たっても取引報告が届かなければ、クライアントへの催促文を承認に回す(11/14追加) |
| 判断の基準 | 報酬の発生時点・率・終了後の対象期間は、クライアント設定の報酬条件に従う。紹介登録が確定していない買い手は対象外(人に確認)。契約終了後の対象期間内の受注も対象 |
| 自律度 | 計算:L4。請求書の送付:L3(2名承認) |
| 人に回す条件 | 紹介登録と受注の時期が前後する / 受注の変更・取消・返品があった / クライアントが明細に異議 |
| 禁止事項 | 契約にない率や基準で計算しない / 根拠のない金額を明細に載せない |
| ツールと権限 | SalesOrder・Contract・台帳の読み取り、Commissionの書込み、請求書の下書き |
| 品質の評価 | クライアントとの明細の不一致0件 |
| 失敗時の処理 | 計算の元データが欠けている→その受注は「計算保留」として明細に分けて載せる |
