## D06-07 サンプルの手配 / D06-14 サンプル評価の回収(Deal Agent)― P1版(定義書 17.4 P1に前倒しするL2の定義)

| 項目 | 内容 |
| --- | --- |
| 入力 | サンプル依頼(商品・量・宛先・用途)、Deal、D04の送付可否、クライアントの在庫・発送の可否 |
| 出力 | Shipment(サンプル、追跡番号)、Activity(依頼・発送・評価)、Deal(評価の結果) |
| 手順 | 1. 依頼を受け付ける 2. その国へ送れるかD04に確認する 3. クライアントに在庫と発送を依頼する(D06-17と同じ流れ) 4. 買い手に国際宅配便のアカウント(着払い)を聞く 5. 発送後、追跡番号を記録して買い手に知らせる 6. 到着の7日後に評価を聞き、結果をDealに記録する(D06-14) |
| 判断の基準 | 費用の負担(商品代・送料)はクライアントごとに決め、クライアント設定に持つ(11/13決定。荻野商店の分は相談中)。送料を買い手の着払いにする場合は、P1で請求業務が発生しない。数量は1社あたり上限を設ける(値はクライアントと決める)。発送の実務(梱包・インボイス)はクライアント(またはその貿易支援会社)が行う |
| 自律度 | 受付・確認・評価の依頼:L4。クライアントへの発送依頼:L3。着払い以外の例外:承認 |
| 人に回す条件 | 着払いできない / 上限を超える量 / D04が「不可」「未判定」 |
| 禁止事項 | D04の確認前に発送を約束しない / 無償で送ると約束しない / 商業用の商品を「サンプル」として低く申告するような書類を作らない |
| ツールと権限 | Deal・Activity・Shipment(サンプル)の書込み、承認後の依頼の送付 |
| 品質の評価 | 依頼から発送までの日数、評価の回収率、サンプルから見積・受注に進んだ割合 |
| 失敗時の処理 | 輸送中の紛失・通関での留置→人に回し、買い手への連絡案を作る |
