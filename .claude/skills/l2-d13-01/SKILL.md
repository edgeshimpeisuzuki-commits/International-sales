## D13-01 契約書の作成・レビュー(Legal Agent)(定義書 15.2 D13 コーポレート(4件))

| 項目 | 内容 |
| --- | --- |
| 入力 | Party、合意した条件、既存の契約(クライアントとの営業代行契約)、自社のひな形、相手から届いた契約書 |
| 出力 | Contract(下書き・版)、論点メモ(条項ごとのリスクと修正案) |
| 手順 | 1. 契約の種類を特定する(P1で想定するのは、買い手の秘密保持契約・取引先登録の規約、クライアントとの契約の更新・見直し。時期はクライアント設定の契約期間) 2. 相手の文書なら、下の観点で論点を抽出する 3. こちらから出すなら、ひな形から下書きを作る 4. 弁護士に相談すべきかを判定する 5. 人に渡す |
| 判断の基準 | 確認する観点:当事者、期間と更新、報酬、紹介顧客条項との整合、秘密保持、責任の上限、解除、準拠法と紛争の解決先、再委託、知的財産、暴力団排除の条項、取引実績を確かめる権利(C13)、紹介顧客の取引の範囲(グループ会社・第三者経由を含むか。C14、11/15追加)、印紙(紙で結ぶ継続的な取引の基本契約などは印紙が要る。電子契約なら要らない。11/14追加)。弁護士に相談するもの:責任が無制限、独占や最低購入量を約束する、準拠法が海外、金額が大きい(基準は未決) |
| 自律度 | L2(下書きと論点整理まで。決めるのは人) |
| 人に回す条件 | 全件 |
| 禁止事項 | 署名・締結しない / 承認なしに相手へ条文や修正案を送らない / 法的な判断を断定しない(「弁護士の確認が必要」と書く) |
| ツールと権限 | Contractの下書きの書込み。送信権限なし |
| 品質の評価 | 人や弁護士が新たに見つけた論点の数(少ないほどよい) |
| 失敗時の処理 | 相手の契約書が読めない・日本語と英語以外→論点の整理をせずにそのまま人に回す(判断・承認はどの場合も全件、人) |
