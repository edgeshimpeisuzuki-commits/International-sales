## D05-03 Webサイト・LPの運用(Content Agent)(定義書 16.2 発信・問合せ(3件))

| 項目 | 内容 |
| --- | --- |
| 入力 | Content(商品説明・会社紹介)、Policy(プライバシーポリシー)、クライアントから使用を了承された写真・ロゴ |
| 出力 | 自社(営業代理)のWebサイトに置く英語のページ(会社概要・クライアントごとの取扱商品ページ・問合せフォーム・プライバシーポリシー) |
| 手順 | 1. ページの下書きを作る 2. D04-07の表現チェックに回す 3. 初回の公開は承認 4. 以降の更新は商品説明など小さなものに限り事後報告 |
| 判断の基準 | 営業メールから来た買い手が「実在する会社か」「何を売っているか」「どう連絡するか」を確かめられること。問合せフォームの内容はD10-01に届くこと |
| 自律度 | 初回公開・構成の変更:L3。小さな更新:L4 |
| 人に回す条件 | 初回公開、会社の説明・プライバシーポリシーの変更 |
| 禁止事項 | 了承のない写真・ロゴを使わない / 実績を盛らない / 価格を公開しない(問合せで対応) |
| ツールと権限 | Webページの下書きと更新(公開の操作は承認後) |
| 品質の評価 | 問合せフォームの届かない件数0件(月次にテスト送信) |
| 失敗時の処理 | ページやフォームが動かない→D14-07(外部連携)と人へ |
