## D06-16 紹介顧客の登録・台帳管理(Deal Agent)(定義書 5.5 P1で動く追加分の定義(D06-12・16・17・18))

| 項目 | 内容 |
| --- | --- |
| 入力 | Deal(商談設定)、Party、除外リスト(契約時点の既存顧客、契約の別紙)、紹介登録台帳、Contract(紹介顧客条項) |
| 出力 | 紹介登録(状態:通知済み→異議期間中→確定/異議あり)、Activity(通知と回答) |
| 手順 | 1. 商談の設定・見積の依頼・サンプルの依頼・注文の意向のうち、最初のものが起きたら起票する(11/14変更) 2. 除外リストと台帳を照合する(名寄せはD14に依頼) 3. 通知文案(会社名・国・接点の経緯・初回接触日・証跡)を承認に回す 4. 承認後にクライアントへ送る 5. 契約で決めた異議期間(標準:クライアントの営業日で5日)を数え、異議がなければ確定する 6. 月末に台帳をD13(報酬計算)へ渡す 7. 異議が認められた買い手は「除外」とし、営業を止めてやり取りの記録をクライアントに渡す(報酬の対象外。営業を続けるのはクライアントの依頼があるときだけ、11/14追加) |
| 判断の基準 | 同一先の判定＝法人名の一致、メールドメインの一致、同一グループのいずれか。登録は「クライアント×買い手」ごとに作る(同じ買い手でもクライアントごとに別の登録、11/14追加)。異議期間はクライアントの営業日で数える(契約の定め。クライアントの休業日はクライアント設定に持つ) |
| 自律度 | 通知の送付:L3。期限の管理と確定処理:L4 |
| 人に回す条件 | 除外リストとの部分一致 / クライアントから異議 / グループ会社との取引が既にある |
| 禁止事項 | 接触の証跡がない先を登録しない / 除外リスト該当先を登録しない / 異議期間を短縮して確定しない |
| ツールと権限 | 台帳の読み書き、承認後の通知の送付(通知手段はクライアントと要合意) |
| 品質の評価 | 商談を設定したDealの全件に「登録」か「除外の判定」がある(抜けゼロ) / 期限の超過ゼロ |
| 失敗時の処理 | 通知の送付に失敗→期限の計算を始めず、再送を人に依頼 |
