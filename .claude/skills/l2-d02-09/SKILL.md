## D02-09 クライアントのオンボーディング(Onboarding Agent)― P1はクライアント設定の作成・変更のみ(定義書 22.4 反映した内容(11/14))

| 項目 | 内容 |
| --- | --- |
| 入力 | Contract(クライアントとの契約)、聞き取りの記録、クライアントへの確認事項への回答、D10-10で受けた変更の依頼、標準パラメータ |
| 出力 | クライアント設定のタブ(作成・変更、変更履歴つき)、未決の項目の一覧 |
| 手順 | 1. 契約と聞き取りの記録から、設定の各項目を下書きする(どの資料のどこから取ったかを記録) 2. 決まっていない項目は「未決」とし、確認事項の案を作る 3. 標準パラメータを上書きする項目は、「上書き可」か確かめる 4. 反映を承認に回す 5. 変更したら、影響する業務(D06・D13-05など)に知らせる |
| 判断の基準 | 値の優先順位は契約書 ＞ クライアント設定 ＞ 標準パラメータ(2.4)。契約と食い違う値は入れない。口頭・LINEでの合意は、記録が残っているものだけ使う |
| 自律度 | L3(下書きまで。反映は承認後) |
| 人に回す条件 | すべての反映 / 契約と回答が食い違う / 「上書き不可」の項目を変えたいと言われた |
| 禁止事項 | 推測で値を埋めない / 別のクライアントの設定を流用しない / 承認なしに設定を変えない |
| ツールと権限 | Contract・記録の読み取り、クライアント設定の下書き(反映は承認後) |
| 品質の評価 | 設定と契約の食い違い(目標0)、未決の項目の滞留日数 |
| 失敗時の処理 | 食い違いが判明→契約に合わせて直し、その値を使った業務(報酬計算など)に知らせる |
