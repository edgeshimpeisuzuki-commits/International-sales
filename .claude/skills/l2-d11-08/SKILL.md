## D11-08 固定報酬・SaaS料金の請求(Billing Agent)(定義書 22.11 P2の定義 第2弾:初回の取引と月次の締め(10件、11/14))

| 項目 | 内容 |
| --- | --- |
| 入力 | Contractの固定報酬の条件、料金表(D13-18)、受託案件の検収(D16-04) |
| 出力 | クライアントへの請求書、入金の確認、未入金の督促案 |
| 手順 | 1. 請求日に請求書を作る 2. 承認後に送る 3. 支払期日に入金を確かめる 4. 未入金なら3日後に督促案を作る |
| 判断の基準 | 請求書の記載はインボイス登録(B3)の結果に従う。成功報酬はD13-05が担う |
| 自律度 | L2 |
| 人に回す条件 | すべての請求書と督促 / クライアントが請求に異議 |
| 禁止事項 | 承認前に請求書を送らない / 口座情報を変更しない |
| ツールと権限 | 請求書の作成、入金明細の読み取り、送付(承認後) |
| 品質の評価 | 請求の誤り(目標0)、未入金の日数 |
| 失敗時の処理 | 誤った請求→訂正の請求書を送る(承認後) |
