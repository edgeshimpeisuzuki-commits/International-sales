## 12.2 適合判定・分類(Regulatory Agent ＋ Classification Utility)

| 項目 | 内容 |
| --- | --- |
| 担当L2 | D04-02 商品×国の適合判定(P1)、D04-03 HSコード分類・関税率の算定(P1)、D04-09 EPAの適用・原産地の判定(P2) |
| 入力 | Product・SKU(成分・原材料の産地・加工工程・包装)、Regulation、Certification、クライアントの規格書・検査成績 |
| 出力 | ProductCompliance(判定・根拠・必要書類・未充足の要件)、HSCode(国別の品目番号・関税率・特恵税率)、原産地の判定記録 |
| 手順 | 1. 商品の情報がそろっているか確認する(不足はD02経由でクライアントへ依頼) 2. HSコードの候補を理由つきで出す 3. 国の規制ルールと商品を項目ごとに照合する 4. 判定案(4種類のどれか)と根拠を作る 5. 承認に回す 6. EPAは、関税が下がる場合に限り原産地の基準を確認する |
| 判断の基準 | 規制ルールの全項目を満たす→提案可。受注までに満たせる→条件付き可。満たせない→不可。情報が足りない→未判定。HSコードは6桁(世界共通)と各国の細分を分けて記録し、候補が複数ある場合は通関業者に確認 |
| 自律度 | 適合判定:L2(昇格しない)。HSコード・EPA:L3 |
| 人に回す条件 | 全件(判定の確定は人)。特に、新しい国×品目区分の初回、添加物や複数の原料を含む商品、有機など認証をうたう商品は専門家の確認を推奨 |
| 禁止事項 | 商品情報が足りないまま「提案可」にしない / 別の国の判定を流用しない / 関税を下げるために事実と異なるHSコードを選ばない |
| ツールと権限 | Product・Regulation・Certificationの読み取り、ProductCompliance・HSCodeの書込み(確定は承認後) |
| 品質の評価 | 専門家・通関業者の確認で覆った割合、判定後の誤り0件、未判定の滞留日数 |
| 失敗時の処理 | 判定の誤りが判明→「未判定」に戻し、D06に影響案件を通知。すでに出荷があればD12(インシデント)へ |
