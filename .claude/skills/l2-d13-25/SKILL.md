## D13-25 自社の経費の支払い・精算と証憑の保存(Accounting Agent)(定義書 21.6 反映した内容(11/13))

| 項目 | 内容 |
| --- | --- |
| 入力 | 受け取った請求書・領収書(メール・Web・紙)、クレジットカードの利用明細、立替の申告、Contract(外注先、個人か法人か)、Budget |
| 出力 | 証憑の保存記録(取引日・金額・取引先で検索できる形)、LedgerEntry、Payment(出金の依頼)、源泉徴収の記録 |
| 手順 | 1. 請求書・領収書を受け取ったら、電子で受け取ったものは電子のまま保存し、取引日・金額・取引先を付ける 2. 適格請求書の登録番号の有無を記録する 3. 個人への報酬は源泉徴収の対象か確かめ、差し引き額を出す。海外の個人・会社への支払いは、非居住者の源泉徴収と租税条約の扱いを税理士に確かめる(11/14追加) 4. 支払いの予定をD13-08の資金繰りに渡し、支払いを承認に回す 5. 仕訳を作り、月次でカード明細と照合する 6. 源泉徴収した税金の納付期限をD12-11に登録する |
| 判断の基準 | 電子で受け取った証憑を紙だけで残さない。こちらから電子で送った請求書(D13-05・D11-08)も同じように保存する。訂正・削除を防ぐ事務処理規程を備える(電子帳簿保存法。規程の形は税理士と確認、12/1前。11/14追加)。保存期間は標準パラメータ(原則7年。欠損金を繰り越す年度の分は10年)。予算にない費用、月額の契約の新規・増額は人が判断。源泉徴収の要否が不明なものは税理士に確認 |
| 自律度 | L3(保存・仕訳・照合は自動。支払いは2名承認) |
| 人に回す条件 | すべての支払い / 明細と証憑が合わない / 証憑がない支出 / 予算外の費用 |
| 禁止事項 | 証憑を書き換えない・削除しない / 送金を実行しない(依頼まで) / カード番号や口座の認証情報を記録しない |
| ツールと権限 | メールの請求書・領収書の読み取り、証憑の保存先への書き込み(上書き不可)、会計ソフトへの仕訳の作成 |
| 品質の評価 | 証憑のない支出(目標0)、月次の照合での不一致の件数 |
| 失敗時の処理 | 証憑が見つからない→取引先に再発行を依頼。保存漏れが判明→保存し、原因を週次の見直しに出す |
