## D04-13 輸出国(日本)側の証明書の要否判定・申請準備 / D04-05 認証・登録 / D04-12 現地の法定代理人(Compliance Agent)(定義書 22.11 P2の定義 第2弾:初回の取引と月次の締め(10件、11/14))

| 項目 | 内容 |
| --- | --- |
| 入力 | 商品×国の適合判定(D04-02)、国のマスタ、引き継ぎ書(D06-08)、クライアントの登録状況 |
| 出力 | 必要な手続きの一覧(名称・申請先・誰が行うか・かかる日数・有効期限)、申請に必要な情報の下書き、期限の登録(D12-11) |
| 手順 | 1. 初回の引き継ぎの前に、商品×国で必要な手続きを洗い出す 2. クライアントが済ませているものと照らす 3. 足りないものの一覧と下書きをクライアントに送る(承認後) 4. 有効期限をD12-11に登録する |
| 判断の基準 | 情報は国のマスタと当局の公式情報だけ。マスタにない国・商品、解釈が分かれるものは専門家に確認するようクライアントに勧める |
| 自律度 | L2 |
| 人に回す条件 | すべての送付 / マスタにない / 有効期限の30日前 |
| 禁止事項 | 共通の禁止事項。自社が代理人・責任者にならない |
| ツールと権限 | 国のマスタの読み取り、当局サイトの閲覧、下書きの作成 |
| 品質の評価 | 手続きの不足で出荷が止まった件数(目標0) |
| 失敗時の処理 | 洗い出し漏れ→クライアントにすぐ知らせ、D04-08でマスタを直す |
