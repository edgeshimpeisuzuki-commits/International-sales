## D06-08 条件交渉・受注確定(Deal Agent)― P1は代理モデルの引き継ぎのみ(定義書 21.6 反映した内容(11/13))

| 項目 | 内容 |
| --- | --- |
| 入力 | Deal(買い手の注文の意向)、Quote(提示した条件)、D06-17の条件確認の結果、ScreeningResult(D12-01)、Contract(クライアントとの代理契約) |
| 出力 | クライアントへの引き継ぎ書(買い手・担当者・商品・数量・条件・希望納期・輸入者・必要書類)、Deal(受注へ)、Commission(紹介登録の確定)、取引報告の依頼 |
| 手順 | 1. 買い手の意向を、商品・数量・価格・納期・支払い・輸入者の項目に分けて確かめる 2. 提示した条件との差があれば、D06-17でクライアントに確認する 3. D12-01の審査が済んでいるか確かめる 4. 引き継ぎ書を作り、承認後にクライアントへ送る 5. 買い手に、以降の契約・請求・出荷はクライアントから連絡があると伝える(承認後) 6. D06-16の紹介登録を「確定」にし、取引報告(月末)の対象に加える 7. 引き継ぎ書に3日返事がなければ催促案を作り、5日で人に回す(11/14追加) |
| 判断の基準 | 契約の当事者はクライアントと買い手。自社は条件を決めない。提示済みの条件と同じならそのまま渡し、異なれば必ずクライアントの確認を先に取る。輸入者・当局への登録(D06-11の聞き取り項目)が不明なら引き継がない |
| 自律度 | L2(引き継ぎ書と連絡文は下書きまで。送付は承認) |
| 人に回す条件 | すべての引き継ぎ / 買い手が自社との契約・自社への支払いを求めた(取引モデルの判断が必要) / 条件の差が大きい |
| 禁止事項 | クライアントに代わって受注を承諾しない / 自社名義で請求書を出さない / 納期・品質を保証しない |
| ツールと権限 | Deal・Quote・Commissionの読み書き、引き継ぎ書の作成、送付(承認後) |
| 品質の評価 | 引き継ぎから初回取引になった割合、引き継ぎ書の不備で問い合わせが来た件数(目標0) |
| 失敗時の処理 | 引き継いだのに取引にならない→理由をクライアントに聞き、Dealに記録。取引報告と紹介登録が食い違う→D13-05の手順で確認 |

## D06-08 条件交渉・受注確定(Deal Agent)― P2で足す部分(定義書 22.9 P2の定義 第1弾:初回受注の前後(4件、11/14))

| 項目 | 内容 |
| --- | --- |
| 入力 | P1の入力に加え、クライアント設定の「交渉の幅」(値引きの上限・MOQの下限・支払条件の選択肢)、買い手の対案 |
| 出力 | 対案への回答の下書き、交渉の記録(提示→対案→合意の履歴)、P1の引き継ぎ書 |
| 手順 | 1. 買い手の対案を項目ごとに分ける 2. 交渉の幅の内か外かを判定する 3. 幅の内なら回答の下書きを作り、承認後に送る 4. 幅の外ならD06-17でクライアントに確認する 5. 合意したらP1の手順(引き継ぎ書)に進む |
| 判断の基準 | 交渉の幅はクライアントが事前に許した範囲だけ。幅の内でも、値引きとMOQの緩和を同時に求められたときはD06-17。最終の受注の承諾はクライアントが行う |
| 自律度 | L2(回答は下書きまで。送付は承認) |
| 人に回す条件 | すべての回答 / 幅の外 / 3往復してもまとまらない |
| 禁止事項 | 幅を超えた条件を提示しない / クライアントに代わって受注を承諾しない / 他の買い手の条件を漏らさない |
| ツールと権限 | P1と同じ |
| 品質の評価 | 幅の外の提示(目標0)、対案から合意までの日数 |
| 失敗時の処理 | 幅の外を提示してしまった→D12-10へ。クライアントに報告し、買い手への訂正は承認後 |
