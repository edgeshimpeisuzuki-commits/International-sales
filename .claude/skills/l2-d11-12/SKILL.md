## D11-12 為替レートの更新(Treasury Agent)(定義書 16.1 市場・商品・価格(6件))

| 項目 | 内容 |
| --- | --- |
| 入力 | 銀行の公表レート、現在のFXRate |
| 出力 | FXRate(公表レート・バッファ・社内レート・適用開始日) |
| 手順 | 1. 毎日、公表レートを記録する 2. 四半期ごと、または社内レートとの差が閾値を超えたら、新しい社内レートを提案する 3. 承認後に更新し、D03-02(価格の再計算)を起動する |
| 判断の基準 | 閾値は±3%(仮)。バッファはクライアント設定で指定した価格表のひな形の設定を使う |
| 自律度 | 記録と提案:L4。社内レートの確定:承認(当面は2名) |
| 人に回す条件 | 閾値の超過(社内レートの変更案) |
| 禁止事項 | 出典のないレートを使わない / 承認なしに社内レートを変えない |
| ツールと権限 | 公表レートの取得(D14-08を通す)、FXRateの書込み |
| 品質の評価 | 公表レートの記録の欠損0日 |
| 失敗時の処理 | 取得できない→前日の値を使わず「未取得」と記録。3日続けば人へ |
