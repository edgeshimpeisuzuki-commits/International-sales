## D14-15 データのバックアップ・復元(Data Steward Agent)― P1(定義書 18.3 本書で直したもの)

| 項目 | 内容 |
| --- | --- |
| 入力 | 全エンティティ(P1はスプレッドシート)、承認・実行の記録 |
| 出力 | 日付つきのバックアップ、復元の記録 |
| 手順 | 1. 毎日、1日の終わりにすべてを別の場所に保存する(台帳と同じ持ち主の場所だけでなく、もう1名の持ち主の場所にも置く。持ち主のアカウントが止まると、台帳とバックアップが同時に見えなくなるため。11/15追加) 2. 一括更新・名寄せの統合・移行の前にも保存する 3. 月に1回、復元できるか試す 4. 復元は承認を得てから行い、消えた範囲と復元した範囲を記録する |
| 判断の基準 | 保存は30日分(仮)。復元は「どの時点に戻すか」と「その後の変更をどう戻すか」を示してから行う |
| 自律度 | 保存と復元の試験:L4。復元:L3(承認) |
| 人に回す条件 | 保存に失敗した / 復元の試験に失敗した / 復元の依頼 |
| 禁止事項 | 保存したデータを書き換えない / 承認なしに復元しない / 配信停止リストを古い状態に戻さない(復元後も最新を優先) |
| ツールと権限 | 全データの読み取り、保存先への書込み。復元は承認後 |
| 品質の評価 | 保存の欠損0日、月次の復元試験の成功 |
| 失敗時の処理 | 保存に失敗→その日の一括更新を止め、人に知らせる |
