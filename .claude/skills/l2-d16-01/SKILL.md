## D16-01 受託サービスの提案・見積(Service Agent)(定義書 20.4 受託サービス(4件))

| 項目 | 内容 |
| --- | --- |
| 入力 | 引合い(Party、依頼内容)、Policy(料金表、D13-18)、KnowledgeArticle(過去案件の工数) |
| 出力 | Engagement(提案)、提案書(目的・範囲・成果物・期間・価格・前提条件・範囲外) |
| 手順 | 1. 依頼を「目的・成果物・期限」に分け、不明点を質問にする 2. D12-01の審査とD12-15の確認を依頼する 3. 使う課と工数を見積もる(過去案件があればその実績) 4. 料金表で価格を出し、提案書を作る 5. 提示を承認に回す |
| 判断の基準 | 範囲外と前提条件(依頼者が出す資料・確認の期限)を必ず書く。料金表の範囲内。工数が過去案件にない種類は幅を持たせ、人が決める |
| 自律度 | L3(提案・価格の提示は2名承認) |
| 人に回す条件 | すべての提示 / 料金表外 / 初めての種類の案件 / 法律・税務の助言にあたる依頼(専門家に回す) |
| 禁止事項 | 成果(売上・採択など)を約束しない / 資格が必要な業務(通関・税務・法律)を引き受けない |
| ツールと権限 | Party・Engagementの読み書き、料金表・ナレッジの読み取り、提案書の作成 |
| 品質の評価 | 受注率、見積と実際の工数の差(±20%以内) |
| 失敗時の処理 | 失注→理由を記録。工数の見積もりが大きく外れた→D16-05で原因を分析し、見積の係数を直す |
