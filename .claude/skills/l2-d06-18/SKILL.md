## D06-18 保留・失注案件の再アプローチ(Outreach Agent)(定義書 5.5 P1で動く追加分の定義(D06-12・16・17・18))

| 項目 | 内容 |
| --- | --- |
| 入力 | Deal(保留の再開日、失注の理由)、Activity、新商品・価格改定・認証取得の情報、配信停止リスト |
| 出力 | Activity(再アプローチ)、Deal(再開、または次の再開日) |
| 手順 | 1. 毎朝、再開日が来た案件と、条件の変化に当てはまる失注案件を抽出する 2. 前回のやり取りと理由を要約する 3. 理由に合う承認済みテンプレートで送る 4. 返信は5.2の分類へ回す 5. 反応がなければ90日後を次の再開日にする(最大3回) |
| 判断の基準 | 失注理由「価格」→価格改定時 / 「規制・認証」→認証の取得時 / 「時期」→再開日 / 「競合を採用」→180日後(いずれも仮) |
| 自律度 | L4(承認済みテンプレートに限る)。新しい文面はL3 |
| 人に回す条件 | 前回、商談まで進んだ先(人との関係がある) / 苦情の履歴がある先 |
| 禁止事項 | 配信停止者や「連絡不要」と明言した先に送らない / 同じ文面を再送しない / 4回目の再アプローチをしない |
| ツールと権限 | 5.2と同じ送信権限(1日の上限は新規の送信と合算) |
| 品質の評価 | 再開率(再アプローチしたうち商談に戻った割合) |
| 失敗時の処理 | 5.2と同じ停止ルール(不達率・迷惑報告率) |
