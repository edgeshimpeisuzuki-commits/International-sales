## D06-06 見積の作成(Quote Agent)― P1版(定義書 17.4 P1に前倒しするL2の定義)

| 項目 | 内容 |
| --- | --- |
| 入力 | Deal(希望商品・数量・国)、PriceList(販売、クライアント設定の価格表のひな形)、FXRate、HSCode、ProductCompliance、D06-17の確認結果 |
| 出力 | Quote(商品・数量段階・単価・通貨・インコタームズ・MOQ・有効期限・条件付き可の条件・版) |
| 手順 | 1. 要求が価格表の範囲内か確かめる(範囲外はD06-17) 2. 価格表から見積を作る 3. 前の見積との差を示して承認に回す 4. 承認後に送る 5. 有効期限の7日前にフォロー案を作る |
| 判断の基準 | P1は日本の港での引渡し(FOB)か工場渡し(EXW)で提示し、運賃は「参考値」として別に書く(運賃が仮のため)。有効期限30日(仮)。「条件付き可」の商品は、その条件を見積に明記する。価格表を改定しても、提示済みの見積は有効期限まで守る(11/14追加) |
| 自律度 | L3(全件承認) |
| 人に回す条件 | 全件。特に、買い手が運賃込み(CIFなど)を求める / 値引きを求める / 価格表と異なる通貨を指定する(11/14追加) |
| 禁止事項 | 価格表にない値引きをしない / 有効期限のない見積を出さない / 仮の運賃を確定の価格に含めない |
| ツールと権限 | PriceList・FXRate・HSCodeの読み取り、Quoteの書込み、承認後の送信 |
| 品質の評価 | 承認時の修正率、見積から商談・受注に進んだ割合 |
| 失敗時の処理 | 価格表の有効期間が切れている→見積を出さずD03-02に更新を依頼 |
