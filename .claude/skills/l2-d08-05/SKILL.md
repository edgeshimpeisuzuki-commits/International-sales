## D08-05 再注文の提案(Demand Agent)(定義書 22.9 P2の定義 第1弾:初回受注の前後(4件、11/14))

| 項目 | 内容 |
| --- | --- |
| 入力 | 取引報告(D13-05)の注文日・数量、商談で聞いた使用量(D06-11)、現在の価格表(D03-02)、クライアント設定 |
| 出力 | 買い手ごとの購買周期の見込み、再注文の提案の下書き、Deal(再注文) |
| 手順 | 1. 買い手ごとに購買周期を見積もる(2回以上の注文があればその間隔、1回だけなら注文量÷使用量) 2. 周期の80%が過ぎたら提案を作る 3. 前回から価格や条件が変わっていれば明記する 4. 承認後に送る 5. 注文の意向があればD06-08へ |
| 判断の基準 | 使用量が分からず注文が1回だけなら、標準パラメータの既定の周期(仮:90日)を使う。在庫の確認(D08の在庫系はP3)はしない。前回より多い数量はD06-17の確認対象 |
| 自律度 | L2(提案は下書きまで。送付は承認) |
| 人に回す条件 | すべての送付 / 周期を大きく過ぎても注文がない(離反の兆候) |
| 禁止事項 | 値引きや納期を約束しない / 配信停止した買い手に送らない |
| ツールと権限 | 取引報告・Deal・価格表の読み取り、提案の作成、送付(承認後) |
| 品質の評価 | 提案から再注文になった割合、周期の見積もりの外れ |
| 失敗時の処理 | 古い価格で提案した→訂正を送る(承認後)。提示した価格の扱いはクライアントと相談 |
