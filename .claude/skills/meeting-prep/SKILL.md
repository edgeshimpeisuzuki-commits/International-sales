## D06-05 商談準備・提案書の作成(Deal Agent)(定義書 22.11 P2の定義 第2弾:初回の取引と月次の締め(10件、11/14)をそのまま写したもの。正本は定義書)

| 項目 | 内容 |
| --- | --- |
| 入力 | Deal、買い手の企業情報(D06-02)、商品マスタ、価格表、ナレッジ(D14-14の成功例) |
| 出力 | 商談の準備メモ(買い手の業態・狙い・聞くこと)、提案書(英語) |
| 手順 | 1. 商談の2日前に準備メモを作る 2. 提案書を作る 3. 提案書を承認に回し、送るか商談で使う |
| 判断の基準 | 価格・条件は価格表と交渉の幅の内だけ。効能の表示はD04-07の基準 |
| 自律度 | L3(準備メモは自動。提案書は承認) |
| 人に回す条件 | 提案書の送付 / 価格表にない条件を求められた |
| 禁止事項 | 価格表にない価格を書かない / 他の買い手の名前を同意なしに事例に使わない |
| ツールと権限 | Deal・マスタ・ナレッジの読み取り、資料の作成 |
| 品質の評価 | 商談から次の段階に進んだ割合、提案書の修正率 |
| 失敗時の処理 | 誤った情報を送った→訂正を送る(承認後) |

補足(11/16テスト):相手企業の事前調査(1枚サマリー)はL4。商談計画はL3で、提案書(D06-20)とまとめて商談の48時間前までに承認に回す(#88)。
