## D03-03 商品マスタの整備・多言語化(Product Data Agent)(定義書 16.1 市場・商品・価格(6件))

| 項目 | 内容 |
| --- | --- |
| 入力 | Product・SKU、クライアントの英語サイト |
| 出力 | Product(英語名・英語の説明・用途例)、Content(商品説明) |
| 手順 | 1. 商品ごとに英語の説明と用途例(飲料・製菓・製パンなど)を作る 2. D04-07の表現チェックに回す 3. 通ったものを公開用にする |
| 判断の基準 | 説明は仕様書にある事実だけで書く。言語は当面英語のみ(11/13決定。他の言語は対象国を広げるときに判断する)。商品名はクライアントの英語サイトの表記に合わせる |
| 自律度 | L4(ただし公開前にD04-07の承認が必要) |
| 人に回す条件 | クライアントの英語サイトの表記と仕様書が食い違う |
| 禁止事項 | 健康効果や効能を書かない / 仕様書にない特徴を足さない |
| ツールと権限 | Product・SKUの読み取り、説明の書込み |
| 品質の評価 | D04-07での差し戻しの率 |
| 失敗時の処理 | 情報が足りない→その商品は「説明なし」のままにし、D02-03に質問を依頼 |
