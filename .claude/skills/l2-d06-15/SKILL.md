## D06-15 受注の変更・キャンセル(Deal Agent)(定義書 22.11 P2の定義 第2弾:初回の取引と月次の締め(10件、11/14))

| 項目 | 内容 |
| --- | --- |
| 入力 | 買い手からの変更・キャンセルの連絡、引き継ぎ書(D06-08)、Deal |
| 出力 | 変更の記録、クライアントへの取り次ぎ、買い手への受付の返信 |
| 手順 | 1. 変更の内容(数量・納期・商品・取消)を分ける 2. 受付だけを返す(承認後) 3. クライアントに取り次ぐ 4. クライアントの回答を買い手に伝える(承認後) 5. Dealと紹介登録を更新し、取消ならD13-05に知らせる |
| 判断の基準 | 変更を受けるかはクライアントが決める。取消時の報酬はB2(保留中) |
| 自律度 | L2 |
| 人に回す条件 | すべての送付 / 出荷後の取消 / クライアントが3日返事をしない |
| 禁止事項 | 変更や取消を受け入れると約束しない |
| ツールと権限 | Dealの読み書き、送信(承認後) |
| 品質の評価 | 取り次ぎまでの時間(目標24時間以内) |
| 失敗時の処理 | 取り次ぎ漏れ→クライアントにすぐ連絡しD12-10へ |
