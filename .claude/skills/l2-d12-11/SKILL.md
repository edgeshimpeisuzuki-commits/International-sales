## D12-11 認証・登録・許認可・商標の期限管理(Regulatory Agent)(定義書 15.1 D12 リスク・コンプライアンス(4件))

| 項目 | 内容 |
| --- | --- |
| 入力 | Certification、License、Trademark、ScreeningResult、Filing |
| 出力 | 期限のアラート、更新の下書きの依頼、期限切れの表示 |
| 手順 | 1. 毎朝、全件の期限を確認する 2. 90日前・30日前・7日前に担当部門と人へ知らせる 3. 期限が切れたものは「期限切れ」にして使わせない 4. 影響する商品×国の再判定をD04に依頼する |
| 判断の基準 | 期限は証書に書かれた日を正とする。期限の書かれていない検査成績は、発行から1年(仮、D06-12と同じ) |
| 自律度 | L4(更新の申請は承認) |
| 人に回す条件 | 7日前になっても更新の下書きがない / 期限切れの証書が取引中の案件に関係する |
| 禁止事項 | 期限を推測で入れない / 期限切れを「有効」のままにしない |
| ツールと権限 | 各データの読み取り、状態(有効 / 期限切れ)の書込み、社内への通知 |
| 品質の評価 | 期限切れの証書の提出0件、期限内の更新率 |
| 失敗時の処理 | 期限のないデータを見つけた→D14の品質アラートとして扱い、入力を依頼 |
