定義書 D01-02。L3(確定は2名の承認、クライアントへの送付も承認後)。

## 手順
1. クライアント設定(定義書のクライアント設定タブ、config/clients/<client>.yaml)から、対象国・ICP・優先商品・良い買い手の条件を読む。
2. 社数とスケジュールを1日の送信上限から逆算する(1社あたり最大3通)。例:20〜40通/日なら、300社を送り終えるのはおよそ2か月後、500社はおよそ3か月後。
3. 1枚にまとめる:対象国 / 狙う業態 / 接触する社数 / スケジュール / 報告の頻度 / 活動の目標(送信・返信・商談の件数)/ 前提(送信開始日、上限、未決事項)。
4. 2名の承認に回す。承認後、クライアントへの送付案を作る(送るのは人)。
5. 合意した日・相手・版を台帳と docs/decisions に記録してから、D06(販売部)を動かす。
6. 月次に返信率・商談化率でICPを見直す。変えるときは同じ手順で合意し直す。

## 判断の基準
- 目標は活動の量で書き、受注や売上は約束しない。
- D04が「不可」「未判定」とした国×商品を優先商品にしない。
- 運賃・関税などのデータがなければ「仮置き」と書く。推測で埋めない。
