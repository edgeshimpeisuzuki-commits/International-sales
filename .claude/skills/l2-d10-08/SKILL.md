## D10-08 買い手の輸入支援・初回取引の案内(Account Agent)(定義書 22.9 P2の定義 第1弾:初回受注の前後(4件、11/14))

| 項目 | 内容 |
| --- | --- |
| 入力 | 商談で聞いた輸入体制(D06-11)、商品×国の適合判定(D04-02)、国のマスタ(輸入の登録・書類)、輸出国側の証明書(D04-13)、引き継ぎ書(D06-08) |
| 出力 | 初回取引の案内書(輸入者になる人、必要な登録、書類、取引の流れ、かかる日数の目安)、不足しているものの一覧、クライアントへの共有 |
| 手順 | 1. 買い手の輸入体制と、国・商品で必要なものを照らし合わせる 2. 足りないものを一覧にする 3. 登録がない買い手には、一般的な取り方(自分で登録する / 輸入代行の業者を使う)を案内する 4. 案内書を承認に回し、買い手に送る 5. 同じ内容をクライアントにも共有する 6. そろったらD06-08の引き継ぎに進む |
| 判断の基準 | 案内は国のマスタにある一般的な情報だけ。個別の法的な判断はしない。マスタにない国・商品は人に回す。輸入代行の業者の紹介は、特定の業者を推薦せず候補を並べる |
| 自律度 | L2(案内書は下書きまで。送付は承認) |
| 人に回す条件 | すべての送付 / マスタにない国・商品 / 買い手が自社に輸入者になるよう求めた(取引モデルの判断) |
| 禁止事項 | 自社が輸入者にならない / 登録や通関が通ると保証しない / 買い手の代わりに当局に申請しない |
| ツールと権限 | 国のマスタ・Dealの読み取り、案内書の作成、送付(承認後) |
| 品質の評価 | 案内の後、登録や書類の不足で初回取引が止まった件数 |
| 失敗時の処理 | 案内の誤りが判明→買い手とクライアントに訂正を送る(承認後)。国のマスタをD04-08で直す |
