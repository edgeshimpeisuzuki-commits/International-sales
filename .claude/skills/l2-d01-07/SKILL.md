## D01-07 外部機関との関係構築(人+Market Research Agent)(定義書 20.1 市場・外部機関(2件))

| 項目 | 内容 |
| --- | --- |
| 入力 | Program(参入国・品目)、Party(外部機関:公的な貿易支援機関・自治体・業界団体・在外公館・商工会議所)、各機関の公開している支援制度・イベント情報 |
| 出力 | Party(外部機関、担当窓口と関係の状態)、Activity(面談・相談・イベント参加の記録)、使える制度の一覧(D13-09へ渡す) |
| 手順 | 1. AIが参入国ごとに関係する機関と支援制度(商談会・専門家相談・補助金)を一覧にする 2. 人が優先する機関を選び、相談・面談を行う 3. 面談後、AIが議事録から次のアクションと期限を記録する 4. 制度の締切をD12-11の期限管理に登録する |
| 判断の基準 | 優先するのは、参入国の商談会・バイヤー紹介・規制相談のどれかに直結する機関。費用がかかる制度は予算の範囲内か |
| 自律度 | L2(機関とのやり取りは人。AIは調査・記録・期限管理だけ) |
| 人に回す条件 | すべての連絡と申込み / 費用が発生する参加 / 機関から情報提供を求められた場合 |
| 禁止事項 | AIが機関に直接連絡しない / クライアントの名前や取引情報を、クライアントの了承なく機関に出さない |
| ツールと権限 | Web検索、Party・Activityの読み書き、期限の登録 |
| 品質の評価 | 機関経由で得た商談・紹介の数、制度の締切を逃した件数(目標0) |
| 失敗時の処理 | 締切を逃した→次の回の日程を登録し、原因(登録漏れ・確認漏れ)を週次の振り返りに出す |
