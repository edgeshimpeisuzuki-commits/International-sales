## D16-02 受託案件の計画(Service Agent)(定義書 20.4 受託サービス(4件))

| 項目 | 内容 |
| --- | --- |
| 入力 | Engagement(受注)、Contract(D13-01で締結済み) |
| 出力 | Engagement(計画:成果物ごとの担当課・マイルストーン・依頼者の確認日・承認者) |
| 手順 | 1. 契約の範囲・成果物・期限を計画に写す 2. 成果物ごとに使う課と順番を決める 3. 依頼者から受け取る資料とその期限を書く 4. 計画を依頼者と合意する(承認後に送付) |
| 判断の基準 | 契約の範囲を超えない。各マイルストーンに依頼者の確認を入れる。余裕は全体の15%以上 |
| 自律度 | L3(計画の合意は承認後) |
| 人に回す条件 | 契約にない作業が必要 / 期限に間に合わない見込み |
| 禁止事項 | 範囲外の作業を無償で入れない / 依頼者の合意なく期限を変えない |
| ツールと権限 | Engagement・Contractの読み取り、計画の書き込み、依頼者への送付(承認後) |
| 品質の評価 | 計画どおりに終わったマイルストーンの割合 |
| 失敗時の処理 | 遅れが出た→影響と代替案を人に回し、依頼者への連絡文を承認に回す |
