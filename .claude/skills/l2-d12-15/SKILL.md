## D12-15 利益相反の確認・情報隔離(Screening Agent)(定義書 20.3 経営管理・統制(5件))

| 項目 | 内容 |
| --- | --- |
| 入力 | Party(新しいクライアント候補とその商品・対象国)、既存クライアントのContract(独占・競合条項)、Policy(利益相反の基準) |
| 出力 | 判定記録(競合なし / 一部競合 / 受けられない)、受ける場合の条件(情報の仕切り、両社への開示)、Actor(アクセス権限の設定案、D14-06へ) |
| 手順 | 1. 候補の商品カテゴリ×対象国×チャネルを、既存クライアントと照合する 2. 既存契約の独占・競合禁止条項に触れるか確かめる 3. 重なる場合は、重なる範囲と、受けるなら必要な仕切りを書く 4. 判定を承認に回す 5. 受ける場合、クライアントごとにデータ・フォルダ・買い手リストを分ける設定をD14-06に依頼する |
| 判断の基準 | 同じ商品カテゴリ×同じ国×同じ買い手層なら「競合」。競合でも、両社に開示して了承を得、買い手の割当ルールを決めれば受けられる。独占条項に触れるなら受けない。契約に定めがなくても、代理商は既存のクライアントの許可なく同種の取引をできない(商法28条)ため、既存のクライアントの了承は書面(メール可)で取り、許可として記録する(11/14追加) |
| 自律度 | L3(判定は案まで。受託の判断は2名承認) |
| 人に回す条件 | すべての判定 / 契約後に競合が判明 |
| 禁止事項 | あるクライアントの情報(価格・買い手・条件)を別のクライアントの作業に使わない / 判定のために候補へ既存クライアント名を伝えない |
| ツールと権限 | Party・Contractの読み取り、判定記録の書き込み、権限設定の依頼 |
| 品質の評価 | 契約後に判明した競合(目標0)、情報の混入(目標0) |
| 失敗時の処理 | 情報の混入が判明→D12-10のインシデントとして扱い、影響範囲と両社への説明を人が決める |
