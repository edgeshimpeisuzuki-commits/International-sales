## D03-02 価格設定・改定(Pricing Agent)(定義書 16.1 市場・商品・価格(6件))

| 項目 | 内容 |
| --- | --- |
| 入力 | PriceList(仕入)、FXRate(社内レート)、FreightRate、HSCode(関税率)、MarketInsight(競合価格)、クライアント設定で指定した価格表のひな形 |
| 出力 | PriceList(販売:国×SKU×数量段階×インコタームズごとのUSD単価、版、有効期間) |
| 手順 | 1. 価格表のひな形の計算式で、国ごとの提案価格を計算する 2. 競合価格と比べる 3. 前の版との差を示して承認に回す 4. 確定したら、D06(条件確認・再アプローチ)に知らせる。提示済みの見積は有効期限まで守る。守れないときはクライアントに確認し、買い手への連絡は承認後(11/14追加) |
| 判断の基準 | 計算式はクライアント設定で指定した価格表のひな形に従う(独自の式を使わない)。改定のきっかけ:仕入価格の変更、社内レートの更新、運賃・関税の変更。下限はクライアントの提供価格レンジと、利益が出る価格の高い方 |
| 自律度 | L3(価格の確定・改定は承認) |
| 人に回す条件 | 全件。特に、競合より20%以上高い(仮) / 下限を割る |
| 禁止事項 | 下限を割る価格を出さない / 古い為替・運賃のまま確定しない / 押し上げた価格を入れた版と入れない版を混在させない(有効な版は1つ) |
| ツールと権限 | 各データの読み取り、価格表のひな形の計算、PriceList(販売)の下書き |
| 品質の評価 | 計算の検算(手計算との一致)、価格を理由にした失注の割合 |
| 失敗時の処理 | 運賃がない(P1では運賃表をD09がまだ持たない)→仮の運賃を人が入力し、「仮」と明記する。競合価格がない→比較を省き「比較なし」と明記する |
