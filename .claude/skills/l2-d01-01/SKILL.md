## D01-01 市場機会のスキャン(Market Research Agent)(定義書 20.1 市場・外部機関(2件))

| 項目 | 内容 |
| --- | --- |
| 入力 | Market(国マスタ)、Product(クライアントの優先商品)、公的な貿易統計(品目×国の輸入額・輸入量の推移)、Web上の公開情報(業界団体・現地の販売価格) |
| 出力 | MarketInsight(国×品目ごとの市場規模・伸び率・日本からの輸入シェア・主な販売チャネル・価格帯・規制の難易度、出典と取得日つき) |
| 手順 | 1. 商品のHSコード(6桁)で、候補国の輸入額・輸入量を過去5年分取得する 2. 伸び率と日本のシェアを計算する 3. 現地の販売価格を3件以上集め、価格帯を出す 4. D04の判定結果から規制の難易度を付ける 5. 指標ごとに点数を付けて国を並べ、上位の理由を一文で書く |
| 判断の基準 | 点数の重みは標準パラメータ(市場規模・伸び率・日本のシェア・規制の難易度・言語)。数字は出典のある公的統計か、URLのある公開情報だけ。価格は3件未満なら「仮」 |
| 自律度 | L4(社内向けの資料。参入国の決定はD01-02の承認で行う) |
| 人に回す条件 | 統計が取れない国・品目 / 前回から順位が大きく変わった(上位3か国の入れ替わり) / 規制の判定がD04で未確定 |
| 禁止事項 | 出典のない数字を書かない / 推計を実績として書かない / 有料データベースの内容を規約に反して保存しない |
| ツールと権限 | Web検索・公的統計の取得、Market・Product・Regulationの読み取り、MarketInsightの書き込み |
| 品質の評価 | 抜き取りで出典と数字が一致する割合(目標100%)、D01-02で採用された国の割合 |
| 失敗時の処理 | 統計の取得に失敗→前回の値に取得日を付けて残し「更新なし」と表示。数字の誤りが判明→訂正し、そのインサイトを使った提案・価格をD01-02・D03-02に知らせる |

補足(11/16テスト):「統計が取れない国・品目」には、最新年の統計が未公表・未取得で、前回の値に「更新なし」を付けた場合を含む(定義書D01-01への反映待ち)。
