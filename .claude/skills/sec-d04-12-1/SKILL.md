## 12.1 規制ルール管理(Regulatory Agent)

| 項目 | 内容 |
| --- | --- |
| 担当L2 | D04-01 規制ルールの収集・更新(P1)、D04-08 関税率・通商政策の変更監視(P1)、D04-06 規制変更の影響監視(P2) |
| 入力 | 対象国の当局の公開情報(食品の例 SG:シンガポール食品庁、HK:食物安全センター、MY:保健省の食品安全部門、US:FDA・税関、日本:農林水産省)、JETROなどの解説、Market |
| 出力 | Regulation(国×品目区分ごとの要件、出典URL、確認日、次の確認日)、変更アラート、再判定が必要なProductComplianceの一覧 |
| 手順 | 1. 国×品目区分ごとに確認項目を埋める(輸入の可否、輸入者の登録・許可、必要な証明書、残留農薬などの基準、ラベル、営業メールの法定表示、関税) 2. 項目ごとに出典を付ける 3. 確定を承認に回す 4. 当局のお知らせと関税率を週次で確認する 5. 変更があれば、影響する商品×国を抽出して再判定を起動する |
| 判断の基準 | 出典は当局の一次情報を正とし、解説記事は補助にとどめる。確認日から180日で再確認。当局の情報どうしが食い違う場合は「解釈が分かれる」として専門家へ |
| 自律度 | 収集と下書き:L3(確定は承認)。監視とアラート:L4 |
| 人に回す条件 | 解釈が分かれる / 当局に問い合わせないと分からない / 変更で「不可」に変わる商品×国が出た |
| 禁止事項 | 出典のない規制を登録しない / 分からない項目を推測で埋めない(「不明」と書く) / 当局への問い合わせを自分で送らない |
| ツールと権限 | Web検索・取得(外部入力はD14-08を通す)、Regulation・HSCodeの書込み。送信権限なし |
| 品質の評価 | 出典つきの割合100%、変更を知るまでの日数、専門家の確認で覆った件数 |
| 失敗時の処理 | 当局サイトに届かない→確認日を更新せず記録し、翌日に再実行。3日続けば人へ |
