## D12-01 取引先審査(Screening Agent)(定義書 15.1 D12 リスク・コンプライアンス(4件))

| 項目 | 内容 |
| --- | --- |
| 入力 | Party(候補・既存)、Contact、公開されている制裁対象者の名簿(国連安保理、米国財務省、日本の財務省など)、Web情報 |
| 出力 | ScreeningResult(問題なし / 要確認 / 取引不可、照合した名簿と版、照合日、有効期限) |
| 手順 | 3段階で行う。1. 送信前:会社名を名簿と照合(自動) 2. 商談設定時:代表者名も照合し、悪い報道がないかWebで確認 3. 受注前:有効期限内か確認し、切れていれば再審査 |
| 判断の基準 | 名簿との完全一致→取引不可(案)。表記ゆれを含む部分一致、または不正・制裁に関する報道がある→要確認。それ以外→問題なし。有効期限1年(仮)。国内の取引先(クライアント・外注先・提携先)は、反社会的勢力でないことも確かめ(公開情報と本人の表明)、契約に暴力団排除の条項を入れる(D13-01。11/14追加) |
| 自律度 | 問題なしの判定:L4。要確認・取引不可:L3(人が確定) |
| 人に回す条件 | 要確認・取引不可の全件 / 制裁対象国との取引が疑われる(輸出先や親会社の所在国) |
| 禁止事項 | 一致の疑いを独断で「問題なし」にしない / 審査の結果や理由を相手に伝えない / 古い名簿で照合しない(名簿の版を記録) |
| ツールと権限 | 名簿の取得・Web検索(D14-08を通す)、ScreeningResultの書込み。送信権限なし |
| 品質の評価 | 要確認のうち実際に問題だった割合(空振り率)、審査なしで送信された件数0件 |
| 失敗時の処理 | 名簿を取得できない→その日の審査は「未実施」とし、D06は送信しない |

補足(11/16テスト):相手が審査の省略や審査結果の開示を求めてきたら、返信せずに人とD12-10に回す。
