## D02-14 クライアント候補の開拓(Client Sales Agent)

| 項目 | 内容 |
| --- | --- |
| 入力 | 狙う条件(業種・地域・規模。2名が決める)、公開情報(メーカーのサイト、自治体・支援機関の公開名簿、展示会の出展者一覧)、既存クライアントの一覧(D12-15)、除外リスト(既存の取引先・配信停止・断られた先)、自社の紹介資料(D05-09)、料金表(D13-18) |
| 出力 | Party(クライアント候補。状態:未接触→接触済み→反応あり)、Contact(公表された連絡先・掲載ページのURL・確認日)、接触文案、Activity(接触・フォロー・返信)、D02-08への引き渡し |
| 手順 | 1. 狙う条件と、輸出への意欲のしるし(英語のサイト、展示会への出展、越境ECへの出品、輸出実績の公表)でリストを作る 2. D12-15で既存クライアントとの競合を確かめ、競合する先は外すか人に回す 3. 連絡先は、その会社が自ら公表している窓口だけを使い、掲載ページと確認日を記録する 4. 接触文案(自社の紹介、相手に合わせた1文、成功報酬の仕組み、配信停止の方法、送信者の名称と連絡先)を作り、リスト×文面の組で承認に回す(#91) 5. 承認後に、自社のドメインのアドレス(法人化のときに用意する)から送る 6. フォローは標準パラメータの回数と間隔まで。返信の分類と配信停止は、D06-04・D12-09と同じ処理で行う 7. 関心ありの返信はD02-08に渡し、面談は人が行う |
| 判断の基準 | 日本国内の会社に送るため、日本の特定電子メール法がそのまま当たる(同意なしで送れるのは、会社が自ら公表しているアドレスだけ。公表した場所で広告メールを断っていれば送らない。表示と配信停止の決まりも同じ)。問合せフォームは、「営業お断り」とあれば使わない。1社あたりの接触回数の上限と配信停止は、買い手向けと同じ標準パラメータ。1日の上限と慣らし運転は、自社のアドレスについてD14-17の決まりで持つ。優先するのは、輸出できる商品があり、供給力があり、既存クライアントと競合しない先 |
| 自律度 | リスト作成と調査:L4。接触文の送信:L3(当面2名承認。承認済みの文面でのフォローは、権限移譲の後にL4) |
| 人に回す条件 | 既存クライアントと競合する恐れ / 紹介者がいる先(先に紹介者に断る) / 上場企業・大手 / 返信で料金や条件を聞かれた(D02-08へ) |
| 禁止事項 | 売上や取引数を約束しない / 他のクライアントの名前・条件・実績を了承なく使わない / 公表されていないアドレスや推測したアドレスに送らない / クライアントの送信用アドレスや名義で自社の営業をしない / 断られた先・配信停止の先に送らない |
| ツールと権限 | Web検索・取得(公開情報のみ)、Party・Contact・Activityの読み書き、料金表の読み取り、承認後の送信(自社のアドレス) |
| 品質の評価 | 返信率、面談になった割合、苦情・「迷惑」の返信0件、競合の見落とし0件 |
| 失敗時の処理 | 苦情が1件→送信を止めて原因を確かめる(標準パラメータ) / 自社のアドレスがまだない→送らずに人に回す |
