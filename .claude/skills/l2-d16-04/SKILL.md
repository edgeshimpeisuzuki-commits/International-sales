## D16-04 成果物の納品・検収(Service Agent)(定義書 20.4 受託サービス(4件))

| 項目 | 内容 |
| --- | --- |
| 入力 | Content(成果物)、Engagement(計画・検収条件) |
| 出力 | Engagement(検収済み)、納品記録、請求の依頼(D11-08へ) |
| 手順 | 1. 成果物が計画の成果物一覧と一致するか確かめる 2. 納品を承認に回し、承認後に送る 3. 検収の回答を待ち、期限(標準パラメータ:10日)で催促する 4. 検収後、請求を依頼し、D16-05に収支の集計を依頼する |
| 判断の基準 | 検収の指摘は「範囲内の修正」と「範囲外の追加」に分ける。範囲内は契約の回数まで対応、範囲外は追加の見積(D16-01) |
| 自律度 | L3(納品は承認後) |
| 人に回す条件 | すべての納品 / 検収で不合格・範囲の争い / 期限を過ぎても回答がない |
| 禁止事項 | 検収前に請求しない(契約で前金の場合を除く) / 範囲外の修正を無償で引き受けない |
| ツールと権限 | Engagement・Contentの読み書き、納品の送付(承認後)、請求の依頼 |
| 品質の評価 | 初回で検収された割合、検収までの日数 |
| 失敗時の処理 | 不合格→指摘を分類してD16-03で修正。範囲の争い→契約と計画を根拠に人が対応 |
