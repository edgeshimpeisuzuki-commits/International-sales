0. 公開情報だけを使う(有料の企業DB・アドレス検証サービスは使わない。11/15決定)。情報源URLと取得日を全件に付ける
1. ICPから検索条件を作る 2. 目標社数の1.5倍を集める 3. 重複と除外リストを落とす 4. 窓口を調べる(購買・商品開発の責任者を優先)。記録するのは「その組織が自ら公表している連絡窓口の掲載ページURLと確認日」まで 5. アドレスは抜き出さない。人が掲載ページを開いて確かめ、Contactの検証結果を「人が確認済み」にしたものだけが送信対象(定義書19.1 A24:SG・HKの法律はソフトで集めたアドレスへの送信を禁止。専門家確認まで)。掲載ページに営業・広告メールお断りの記載があれば除外リストへ 6. 点数を付ける(config/standard-params.yaml の scoring) 7. D12に審査を依頼する 8. リストを承認に回す

## 自律度・人に回す条件・禁止事項(定義書5.1 D06-01・02をそのまま写したもの。11/16のテストで欠けていたため追加)
| 項目 | 内容 |
| --- | --- |
| 自律度 | L4(リスト作成まで自律)。送信前のリスト承認は5.2のゲートで行う |
| 人に回す条件 | 集まった社数が目標の80%未満 / クライアントの既存顧客らしいが確証がない / 大手(従業員1,000名超など)で人が直接当たるべき先 |
| 禁止事項 | 購入名簿や収集を禁じたサイトから取得しない / 個人の私用アドレスを載せない / 推測したアドレスは、検証できてもその組織が公表していなければ送信対象にしない(日本の特定電子メール法。11/14変更) / アドレスごとに公表されていた場所(URL)と確認日を記録せずに載せない / 公表した場所で広告メールを断る旨がある先を載せない / 機械で集めたアドレスへの送信を禁じている国(シンガポール・香港など。国のマスタ)では、その国の決まりと19.1のA24の扱いに従わずにアドレスを載せない(11/15追加) / 除外リストに該当する先を載せない |
