## D06-12 書類要求への対応(Deal Agent)(定義書 5.5 P1で動く追加分の定義(D06-12・16・17・18))

| 項目 | 内容 |
| --- | --- |
| 入力 | 書類要求(返信・Ticket)、Product、Certification(有効期限つき)、ProductCompliance、保有書類のフォルダ |
| 出力 | 提出書類一式、Activity(提出記録)、不足書類のクライアントへの依頼 |
| 手順 | 1. 要求された書類を特定する 2. 保有書類と突合し、商品・版・有効期限を確認する 3. 不足はクライアントへの依頼文案を作る 4. 提出案(添付と本文)を承認に回す 5. 承認後に送り、提出した版を記録する。買い手の取引口座の登録用紙(サプライヤー登録)は、売り手であるクライアントに転送して記入を依頼し、提出は承認後(P1。D06-13はP2のまま、11/14追加) |
| 判断の基準 | 業種ごとの標準書類一覧に従う。食品の例:規格書、成分・栄養成分、残留農薬・微生物の検査成績、アレルゲン表、認証書。検査成績は発行から1年以内(仮) |
| 自律度 | L3(提出は承認後) |
| 人に回す条件 | 保有していない書類 / 買い手独自の書式でクライアントの署名が要る / 秘密保持契約の要求 |
| 禁止事項 | 期限切れ・別商品の書類を流用しない / 書類を改変しない / 未取得の認証を「取得済み」と書かない |
| ツールと権限 | 保有書類フォルダの読み取り、承認後の送信。Certificationは読むだけ(更新はD04) |
| 品質の評価 | 保有書類なら要求から24時間以内に提出 / 買い手からの差し戻し件数 |
| 失敗時の処理 | 期限切れを検出→提出せず、クライアントへの更新依頼案とD12-11(期限管理)への通知 |
