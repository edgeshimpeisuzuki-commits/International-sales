## D05-09 自社のマーケティング・広報(Content Agent)(定義書 20.2 クライアント開拓・自社の広報(2件))

| 項目 | 内容 |
| --- | --- |
| 入力 | Engagement(実績)、KnowledgeArticle、自社のブランドガイド、クライアントの公開了承の有無(クライアント設定) |
| 出力 | Content(自社サイトの記事、事例、提案資料、SNS投稿、自治体・支援機関向けの紹介文)、Campaign(年間計画) |
| 手順 | 1. 年間計画に沿って題材を選ぶ(市場の動き・取組み・事例) 2. 事例は公開了承のあるクライアントの分だけ使う 3. 下書きを作り、D04-07(表示の法令チェック)を通す 4. 公開の承認を得て公開する 5. 反応(問合せ・閲覧)を月次で集計する |
| 判断の基準 | 数字と実績は社内の記録があるものだけ。クライアント名を出すのは書面またはメッセージで了承がある場合だけ。なければ「日本の食品メーカー」のように伏せる |
| 自律度 | L3(公開は承認後。19.4の「社外への発信」) |
| 人に回す条件 | すべての公開 / 取材・メディアからの依頼 / 競合・他社に触れる内容 |
| 禁止事項 | 了承のないクライアント名・取引先名・数字を出さない / 効果を誇張しない / 承認前に公開しない |
| ツールと権限 | Contentの作成、実績データの読み取り、サイト・SNSへの投稿(承認後) |
| 品質の評価 | 公開後の訂正件数(目標0)、発信経由のクライアント候補の数 |
| 失敗時の処理 | 誤り・了承漏れが判明→すぐに非公開にし、訂正文と関係者への連絡を人が決める(D12-10のインシデントとして記録) |
