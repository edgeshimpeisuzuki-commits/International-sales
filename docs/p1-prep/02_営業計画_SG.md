# 営業計画 シンガポール(案 v0.1・11/16)

- 定義書:D01-02(営業計画の合意)、19.6の判定の13、3章(P1→P2の移行条件)
- 状態:案。2名の承認のあと荻野商店に送り、合意した日・相手・版を記録してから送信を始める
- 目標は活動の量で書く。受注・売上は約束しない

## 1. 計画の1枚(荻野商店に送る内容)

| 項目 | 内容 |
|---|---|
| 対象国 | シンガポール(パイロット)。結果を見て香港・マレーシア・米国へ |
| 狙う業態 | 第1波:①日本食材の輸入卸・商社 ②自分で輸入できる規模の食品・飲料メーカー(飲料・アイス・菓子)。カフェ・ベーカリーは卸を通じて届ける |
| 提案する商品 | ほうじ茶パウダー(有機は認証の確認後) |
| 接触する社数 | 目標500社。まず300社で効果を確かめる |
| 進め方 | 1社に最大3通(初回、4日後、10日後)。初回で希望の数量と価格を聞き、条件が合う先から商談 |
| 送信量 | 1日5〜10通から始め、2〜4週間で20〜40通へ(苦情・不達があれば減らす・止める) |
| スケジュール(中位の見込み) | 12/1開始 → 300社に送り終えるのは2月初め、500社は3月初め |
| 報告 | 毎週金曜に簡易報告(送信数・返信・商談)、月末に月次レポート(候補数・反応・ニーズ・発注に至らない原因・有効だった手法) |
| 活動の目標(P1) | 300社への送信を終える / 返信率2%以上 / 苦情・「迷惑」の返信が4週続けて1件以下 |
| 荻野商店にお願いすること | 確認事項への回答、商談で渡せる資料、サンプル、引き合いへの条件の回答 |

## 2. 社数とスケジュールの根拠(1日の上限からの逆算)

送り終える日 = 最後の会社への3通目(10日後のフォロー)まで。返信があった会社のフォローは減るが、返信率2〜3%なので無視して計算。

| 送信量の上げ方 | 300社 | 500社 |
|---|---|---|
| 低め:5通→10通(2週ごと)→20通 | 約84日(2/23頃) | 約127日(4/7頃) |
| 中位:7通→15通→30通 | 約63日(2/2頃) | 約92日(3/3頃) |
| 高め:10通→20通→40通 | 約53日(1/23頃) | 約76日(2/15頃) |

示唆:
- 契約の見直し(2月上旬)の時点で「300社への送信を終えた結果」を出せるのは中位以上のとき。低めだと見直しに間に合わないため、見直しは「途中経過」として扱うことを先に合意しておく。
- 送信量を上げられるかは、苦情・不達の少なさで決まる(D14-17)。社数を増やすより、リストの質(人が確かめた宛先)を保つほうが先。

## 3. 前提と未決

| 前提 | 内容 |
|---|---|
| 送信開始 | 12/1。送信開始の判定(14項目)の2名承認が条件 |
| 宛先の確認 | 送るアドレスは人が公式サイトで1件ずつ確かめたものだけ(A24)。中位の計画では1日15〜30件の確認が要る。人の確認が追いつかなければ、送信量ではなくこちらが上限になる |
| 返信率 | 中東での経験(リストの10〜15%が商談)は参考値で、SGの見込みとしては使わない |
| 未決 | サンプルの上限額、テンプレートの正式承認、代理の名称・連絡先 |
