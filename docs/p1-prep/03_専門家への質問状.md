# 専門家への質問状(案・11/16)

- 定義書:19.1 A15(営業メールの法律は東京都の無料相談)、A24(アドレスの集め方)、D12-09(委託か提供か)、5.2(法定表示の送信者)
- 相談先:TOKYO創業ステーションの弁護士相談(無料)。シンガポール・香港の法律は日本の弁護士では答えられない場合がある。その場合は回答を待たず、A24の扱い(人が1件ずつ確かめたアドレスだけ、香港は送らない)を続ける
- 持参するもの:営業メールの文面(sg-wave1-v0.2.md)、配信停止フォームの設計、プライバシーポリシー案(04)、業務の流れ図(下の1)

## 1. 事業の説明(相談の冒頭で読む)

- 私たち(個人事業主2名、2月に法人化予定)は、日本茶メーカー(株式会社荻野商店)の海外営業を成功報酬で代行しています。
- 荻野商店から提供を受けた同社ドメインのメールアドレスを使い、「荻野商店の海外営業代理」と名乗って、シンガポールの企業に英語の営業メールを送ります(12/1開始予定、1日最大40通程度)。
- 宛先は、相手企業が自社のWebサイトに公表している会社の連絡先だけです。AIが候補の会社と連絡先の掲載ページを探し、メールアドレスは人がそのページを開いて1件ずつ確かめてから使います。
- 返信は荻野商店の受信箱に届き、荻野商店の管理者と私たちの両方が読めます。送信・返信の記録は私たちの台帳(Googleスプレッドシート)に残します。
- 文面の作成や返信の分類に、海外(米国)のAIサービスを使います。

## 2. 質問

### 日本の特定電子メール法
1. この形で送る場合、法律上の「送信者」と「送信委託者」はそれぞれ誰になりますか。表示すべき氏名・名称、住所は、荻野商店と私たちのどちらのもの(または両方)ですか。
2. 相手企業が自社サイトに公表している会社のアドレス(info@ など)は、同意がなくても送れる「自己の電子メールアドレスを公表している者」に当たりますか。サイトに「営業メールお断り」とあれば送らない運用で足りますか。
3. 配信停止の受付を「返信」と「Webフォーム」の2つにし、24時間以内に反映する運用で、受信拒否の通知への対応として足りますか。

### 個人情報保護法
4. 買い手の担当者の連絡先(公表されている会社のアドレスや担当者名)を私たちが集め、荻野商店のメールアドレスでやり取りする場合、私たちは荻野商店から「委託」を受けて扱っているのか、私たちが集めて荻野商店に「提供」しているのか、どちらに当たりますか。提供に当たる場合、記録や同意で何が必要ですか。
5. 米国のAIサービス(Anthropic、Google)に買い手の連絡先やメール本文を入れることについて、プライバシーポリシーに何を書く必要がありますか(外国にある第三者への提供か、委託か。外的環境の把握として何を書くか)。
6. 案(04)のプライバシーポリシーに、不足や誤りはありますか。

### シンガポール・香港(答えられる範囲で)
7. シンガポールの Spam Control Act は、アドレスを探して集めるソフトで集めたアドレスへの送信を禁じています。AIが「連絡先の掲載ページ」を探し、アドレスは人が確かめる運用は、これに当たりますか。当たる恐れがある場合、どの運用なら安全ですか。
8. 件名の `<ADV>`、英語の配信停止の案内、30日以上有効な連絡先を入れる運用で、表示の決まりは足りますか。
9. 日本の弁護士として回答が難しい場合、確認先として適切な窓口(JETROの相談、現地の法律事務所など)を教えてください。
