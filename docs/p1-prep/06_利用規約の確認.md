# AIサービスとメール事業者の利用規約の確認(判定の14・案・11/16)

- 定義書:19.6の判定の14、D14-13
- 確認した使い方:営業メールの下書き(AI)、承認済みの文面の送信(Gmail/Google Workspace)、定時の処理(Claudeの定時タスク)
- 注意:Anthropicの規約は公式ページを開けず、第三者が掲載した写しと報道で確認した。公式ページ(anthropic.com/legal/aup)を人が開いて、同じ文言かを確かめてから判定を「済み」にする

## 1. 規約にある関係する決まり

| サービス | 決まり(要旨) | 出典 |
|---|---|---|
| Anthropic(Claude) | スパムの作成・配布を助ける使い方を禁止。詐欺・フィッシングの文面の作成も禁止 | Usage Policy(第三者掲載の写し) |
| Anthropic(Claude) | 11/12発効の改定で、欺瞞的な商業キャンペーンの禁止を独立した節にまとめた | 報道(contentgrip.com) |
| Google Workspace | 求められていない一斉の商業メールを作る・助ける使い方を禁止(2023年版の利用ポリシー) | workspace.google.com |
| Google Cloud / Workspace(現行) | 求められていない大量のメール・広告・勧誘(スパム)の作成・配布を禁止 | cloud.google.com/terms/aup |

## 2. 私たちの使い方との照合

| 論点 | 私たちの運用 | 評価 |
|---|---|---|
| 「スパム」「求められていない一斉の商業メール」に当たるか | 同意のない相手への営業メールなので、**文字どおり読むと当たりうる**。ただし、量は1日20〜40通、1通ずつ業態に合わせた文面、宛先は相手が公表している会社の窓口だけ、法定表示と配信停止2経路、苦情1件で減速・2件で停止 | **グレー。人の判断が必要(1名)**。量と質で「一斉配信」とは違う運用だが、規約に例外の明記はない |
| 欺瞞的な商業キャンペーン | 代理であることと名義を明記。実績を盛らない。AIで作成したことは書かないが、聞かれたら正直に答える | 当たらないと考える |
| 人間のふりをすること | 送信者は実在の鈴木。返信は人が承認してから送る | 当たらないと考える |
| 定時の処理で受信箱を読む | 鈴木さん本人のアカウントを、本人の了承のもとで読む | 問題なし |

## 3. 判断が必要なこと(1名)

1. 規約の「スパム」との関係をどう考えるか。選択肢:
   - A. 今の運用(少量・個別・法令順守・苦情で止める)で進め、苦情や警告が来たらすぐ止める
   - B. 初回は「問い合わせフォーム経由」や「公表されたB2B窓口のみ」にさらに絞る
   - C. 専門家相談(03)の質問に「サービス規約との関係」を足し、回答を待つ
2. Googleの送信者ガイドライン(送信者の認証・配信停止・迷惑報告率)を、送信開始前に人がもう一度読む。1日5,000通を超える「一斉送信者」の要件には当たらない量だが、迷惑報告率の上限は量に関係なく効く

おすすめ:A+C。送信は少量から始め、規約の論点を専門家の質問状に1問足す。

## 4. 規約に反した場合の影響

| サービス | 影響 |
|---|---|
| Google Workspace(荻野商店のドメイン) | 送信の制限やアカウントの停止。**荻野商店の本業のメールにも影響しうる**(判定の1と同じ論点) |
| Anthropic | 利用の制限・停止。エージェント一式が止まる |
