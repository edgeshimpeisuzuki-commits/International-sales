## 正解(G3-answers.md)についての注記(×にはしていない)

1. G3-07: 商談化の比は 1.57%÷0.79%=1.98倍で、厳密には2倍に届かない。スキルは「前向きな返信と商談化を比べ、2倍以上の差」と書き、yaml は主指標(positive_reply_rate)に `switch_if_ratio_at_least: 2.0` を置いている。主指標で判定する読み方なら正解どおりBで問題ないが、「両方とも2倍以上」と読むと結論が変わる。スキル本文のあいまいさとして下の修正に含めた。
2. G3-09: 正解は「P1では bayes は使わない(スキルにある)」とするが、スキルは「P2以降で送信量が増えたら bayes に変えてよい」と書くだけで、P1での使用を明示的に禁じてはいない。解答の「P1で使うかは2名が決める」も定義と矛盾しないため○とした。正解の根拠の書き方を「P2以降を想定。P1で変えるならyaml+PRで2名」に直すとよい。
3. G3-08: 正解は yaml の status を「stopped(Bのみ停止)」とするが、status は実験全体の値(draft/approved/running/decided/stopped)で、案ごとの停止を表す欄が yaml にない。下の修正案4で欄の追加を提案。
4. 前提: config/experiments/EXP-20261201-approach.yaml の実ファイルは `status: draft`。問題文(G3-07〜09)は running を仮定しており、テスト上の設定として扱った。
